# 🐍 Snake Game

C++과 Qt를 사용하여 제작한 간단한 **Snake Game**입니다.

방향키를 이용해 뱀을 조작하여 사과를 먹고 몸을 성장시키면서 최대한 높은 점수를 획득하는 게임입니다.  
사과를 먹을수록 뱀의 이동 속도가 점점 빨라져 난이도가 증가합니다.

## 🎮 게임 방법

- 방향키 `↑` `↓` `←` `→`를 사용하여 뱀을 조작합니다.
- 빨간색 사과를 먹으면 뱀의 길이가 1칸 증가합니다.
- 사과 하나를 먹을 때마다 **10점**을 획득합니다.
- 사과를 먹을수록 뱀의 이동 속도가 조금씩 빨라집니다.
- 벽이나 자신의 몸에 충돌하면 게임이 종료됩니다.
- 게임오버 후 `R` 키를 누르면 처음부터 다시 시작할 수 있습니다.

## 🕹️ 조작법

| 키 | 기능 |
|---|---|
| `↑` | 위로 이동 |
| `↓` | 아래로 이동 |
| `←` | 왼쪽으로 이동 |
| `→` | 오른쪽으로 이동 |
| `R` | 게임오버 후 재시작 |

## ✨ 주요 기능

- 뱀 이동 및 방향키 조작
- 연속 키 입력으로 인한 잘못된 180도 회전 방지
- 랜덤 위치에 사과 생성
- 사과 획득 시 뱀 길이 증가
- 점수 시스템
- 점진적인 이동 속도 증가
- 벽 충돌 판정
- 자기 몸 충돌 판정
- GAME OVER 화면
- `R` 키를 이용한 게임 재시작

## 🛠️ 개발 환경

- C++
- Qt
- Qt Creator
- Qt Widgets
